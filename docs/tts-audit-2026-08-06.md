## 2. Config Gaps Found

### HIGH — `HF_TOKEN` server fallback never wired
`server/routes/ai.ts` only read `userProfile.huggingFaceToken`; the documented
`process.env.HF_TOKEN` fallback existed only in the (dead) HF Inference path.
→ Fixed: `userProfile?.huggingFaceToken || process.env.HF_TOKEN || undefined`.

### HIGH — Prod container missing HF_TOKEN
Host `/var/www/SynapseJourney/.env` had `HF_TOKEN` set, but the running container
was created without it (env is frozen at `docker run`; app does not use dotenv).
→ Fixed: container recreated with HF_TOKEN injected (image/ports/binds/restart preserved).

### MEDIUM — Dead last-resort fallback
`callHFInferenceTTS` targeted `api-inference.huggingface.co` — DNS-dead (verified:
`getent hosts` fails). Could never succeed; only added latency.
→ Removed function + both call sites.

### LOW — UI copy
Settings said "requires HF token". Now "optional HF token improves reliability"
(server presets endpoint, Settings page).

## 3. Behavioral Change: Anonymous ZeroGPU

- Anonymous `POST /gradio_api/call/generate_custom_voice` → 200, SSE completes, WAV URL returned
